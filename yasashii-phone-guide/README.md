# やさしいスマホ案内 プライバシーポリシー

最終更新日: 2026年9月12日

「やさしいスマホ案内」（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、必要な範囲に限って情報を取り扱います。

## 1. 本アプリで取り扱う情報

本アプリでは、iPhoneの操作案内を行うため、以下の情報を取り扱う場合があります。

- ユーザーが音声または文字で入力した質問内容
- 端末のiOSバージョン
- 直前の案内内容や、ユーザーが選択した「もっと詳しく説明」「できない」などの返答
- ユーザーが自ら選択したスクリーンショットまたは画像
- 音声認識のために入力された音声

本アプリは、利用にあたって氏名、住所、電話番号、メールアドレス等の登録を求めません。

## 2. 音声入力について

本アプリの音声入力には、AppleのSpeechフレームワーク（SFSpeechRecognizer）を使用しています。

音声認識のため、マイクから入力された音声データがAppleの音声認識サーバーへ送信される場合があります。音声認識の処理およびデータの取扱いは、Appleの仕様およびプライバシーポリシーに従います。

本アプリの開発者が、音声そのものを独自のデータベースへ保存する機能はありません。

Appleのプライバシーポリシー:
https://www.apple.com/legal/privacy/jp/

## 3. AIによる案内について

本アプリでは、iPhoneの操作案内を生成するため、ユーザーの質問内容、iOSバージョン、必要に応じて直前の案内内容・ユーザーの返答・スクリーンショットまたは画像を、Cloudflare Workersを経由してOpenAI APIへ送信します。

これらの情報は、ユーザーへの回答を生成する目的でのみ使用します。

本アプリのバックエンドには、質問内容や画像を独自のデータベースへ継続保存する機能はありません。

OpenAI APIへのリクエストでは、生成した応答を後から取得するための保存を行わない設定（store: false）を使用しています。ただし、OpenAIにおけるAPIデータの取扱い・保持については、OpenAIのポリシーが適用されます。

OpenAIのプライバシーポリシー:
https://openai.com/policies/privacy-policy/

Cloudflareのプライバシーポリシー:
https://www.cloudflare.com/privacypolicy/

## 4. 画像について

スクリーンショットや写真は、ユーザーが明示的に選択した場合のみ、質問への回答生成のために送信されます。

画像には、氏名、電話番号、メールアドレス、住所、医療情報、金融情報、パスワードその他の機密情報が含まれる可能性があります。送信前に、不要な個人情報や機密情報が写っていないことをご確認ください。

## 5. 利用目的

本アプリで取り扱う情報は、主に以下の目的で利用します。

- ユーザーの質問内容を理解するため
- iPhoneの操作手順を生成・表示するため
- 直前の案内に続く追加説明を行うため
- 不具合の原因調査やサービスの安定運用を行うため

## 6. 広告・トラッキング

本アプリは、広告配信を目的としたユーザートラッキング機能を使用しません。

また、ユーザーの行動を第三者広告のために追跡することを目的として、広告識別子を利用することはありません。

## 7. 第三者サービス

本アプリでは、機能提供のために以下の第三者サービスを利用します。

- Apple: 音声認識、iOS標準機能
- Cloudflare: 通信処理（Cloudflare Workers）
- OpenAI: AIによる操作案内の生成

各サービスに送信された情報には、それぞれのサービス提供者の利用規約およびプライバシーポリシーが適用されます。

## 8. 個人情報・機密情報の入力について

本アプリは、パスワード、クレジットカード番号、銀行口座情報、健康・医療情報、その他の高度に機密性の高い情報を入力する用途を想定していません。

質問や画像を送信する際は、必要のない個人情報や機密情報を含めないようお願いいたします。

## 9. 子どものプライバシー

本アプリは、子どもの個人情報を積極的に収集することを目的としたサービスではありません。

## 10. 本ポリシーの変更

本アプリの機能変更、利用する外部サービスの変更、法令やガイドラインの変更等に伴い、本ポリシーを変更する場合があります。

変更後の内容はこのページに掲載します。
