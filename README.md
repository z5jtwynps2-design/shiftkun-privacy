# シフト君 プライバシーポリシー

最終更新日: 2026年8月29日

「シフト君」（以下「本アプリ」）は、ユーザーのプライバシーを尊重します。

## 1. 収集する情報

本アプリは、開発者がユーザーの個人情報、利用情報、端末識別子、位置情報、連絡先、広告識別子その他のデータを収集する機能を備えていません。

## 2. アプリ内で入力される情報

ユーザーが本アプリに入力する氏名・メンバー名、勤務希望、固定勤務、祝日設定その他のシフト作成に必要な情報は、シフト作成処理のために端末上で使用されます。

これらの情報を、開発者が管理するサーバーへ送信することはありません。

## 3. シフト計算およびファイル出力

シフト計算およびExcel等のファイル生成は端末上で行われます。

ユーザーがiOSの共有機能等を利用して生成ファイルを他のアプリやサービスへ送信した場合、その送信先におけるデータの取扱いについては、各サービスのプライバシーポリシーが適用されます。

## 4. 広告・解析・トラッキング

本アプリは、広告配信SDK、アクセス解析SDK、ユーザートラッキング機能を使用しません。

## 5. 第三者への提供

本アプリが開発者へユーザーデータを送信・収集しないため、開発者から第三者へユーザーデータを販売または提供することはありません。

## 6. 子どものプライバシー

本アプリはユーザーデータを収集しません。

## 7. 本ポリシーの変更

本アプリの機能変更等に伴い、本ポリシーを変更する場合があります。変更後の内容はこのページに掲載します。

本アプリに関するお問い合わせは、以下のサポートページをご利用ください。
